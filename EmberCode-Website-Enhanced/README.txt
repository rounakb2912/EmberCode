# EmberCode website

## Files
- `index.html` — page structure and content
- `style.css` — responsive visual system and layout
- `script.js` — mobile navigation, scroll reveals, year, and contact form behavior

## Run locally
Open `index.html` in a browser. Internet access is needed for the Google Fonts used by the design.

## Before publishing
1. Replace `hello@embercode.example` in `script.js` with a real inbox.
2. The contact form currently validates fields and opens the visitor's email app using a `mailto:` link. It does not store or transmit leads to a server. For production, connect a backend endpoint or a form service.
3. Replace the illustrative portfolio concepts with real client work before presenting them as case studies.
4. Add your real company address, legal details, privacy policy, and social links if applicable.
